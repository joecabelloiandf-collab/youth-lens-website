# Youth Lens Website – v2 Launch

Static multilingual site (EN/DE/TR/ES) for YOUTH LENS – Real Stories, Real Change.

## Launch files
This repository is the source for the Cloudflare Pages deployment. `index.html` remains at the repository root.

## Included in v2
- Official Youth Lens branding
- Official EU co-funded logo and disclaimer
- CC BY 4.0 footer notice
- Four-language interface
- A1–A4 project roadmap
- Dedicated Activity 2 page
- News articles for Dortmund kick-off and Activity 2 methodology
- Privacy, cookies/local storage, accessibility and legal notice pages
- Favicon and 404 page

## Future update pattern
Add new images to `assets/`, new news pages to `news/`, and update the homepage news cards in `index.html`.
